
# 📘 Technical Documentation Page

This project is a **responsive technical documentation page** built using **HTML** and **CSS**, following the user stories and test cases defined in the requirements.

---

## 🚀 Features

- A fixed **navigation bar** (`#navbar`) on the left side of the screen.
- A **main content area** (`#main-doc`) containing multiple documentation sections.
- At least **five sections**, each with:
  - A header describing the topic.
  - An `id` corresponding to the header text (spaces replaced with underscores).
  - Paragraphs, code snippets, and list items.
- Navigation links (`.nav-link`) that allow smooth navigation to each section.
- A **responsive design** using media queries for smaller devices.

---

## 📑 Sections Included

1. **Introduction**  
   Overview of the documentation.

2. **HTML Basics**  
   Explains the foundation of web structure using HTML.

3. **CSS Fundamentals**  
   Covers styling and layout with CSS.

4. **Best Practices**  
   Guidelines for writing clean and maintainable code.

---

## 🎨 Styling Highlights

- **Sidebar Navigation**  
  - Fixed on the left for desktop screens.  
  - Collapses into the top for mobile devices.  

- **Main Content Area**  
  - Well-structured with readable typography.  
  - Includes styled code blocks and lists.  

- **Responsive Design**  
  - Media query ensures usability on tablets and mobile devices.  

---

## 📱 Responsiveness

- **Desktop & Laptop** → Sidebar always visible on the left.  
- **Mobile & Tablet** → Navbar moves to the top for better readability.  

---

## 🛠️ How to Run

1. Clone or download this project.  
2. Open `index.html` in your browser.  
3. Explore the documentation and test responsiveness by resizing the window.  

---

## ✅ Requirements Fulfilled

- Navigation bar with links corresponding to each section.  
- At least **10 paragraphs**, **5 code blocks**, and **5 list items** across the sections.  
- A fixed navbar for larger screens.  
- Media query for responsiveness.
