HTML Basics

HTML (HyperText Markup Language) structures web content.

<p>This is a paragraph</p>

  • It defines page structure
  • Basic elements include headings, paragraphs, and links
CSS Fundamentals

CSS (Cascading Style Sheets) styles web pages.

body { background-color: lightgray; }

CSS applies styles to HTML elements.

JavaScript Overview

console.log("Hello, world!");
  • Used for dynamic content
  • Enables user interaction
  • Runs in the browser
